Limits

Block generations and completed intervals are observer concepts. Fixtures on the real scheduler check them; snapshots do not. GPU re-prefill time is unavailable, so this report gives only completed re-prefill tokens. Alternative candidates are observations at a decision, not measured outcomes: choosing another victim would change every later allocation. Events within a run share one history, so many preemptions in one run are not independent samples.
