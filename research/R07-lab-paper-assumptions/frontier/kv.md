## Candidate for review

Can an alarm available **before dispatch of a tool call** identify compression-induced errors in schema-valid argument values often enough to justify re-prefilling the affected request? Compare ActKV’s trend, fixed retention, verifying all calls, and the raw model probabilities at value positions. Report correct calls unnecessarily replayed, errors intercepted, remaining errors, bytes and elapsed time. An alarm cannot restore a previously discarded page. Charge the cost to reconstruct it.

This is an empirical question about a controller under eviction. Distinguish pre-mask model scores and post-mask scores, inspect the implementation to identify what the original method consumed, and treat forced tokens separately. A top-k score over a masked distribution needs an explicit rule when fewer than k tokens are allowed. The pre/post-mask distinction is established [K8]. Cache damage to a tool call and full-KV verification are also established [K9–K10]. Neither result demonstrates an economical warning before dispatch.

Pair runs on identical histories and deterministic, harmless fixture calls. Use legal but wrong argument values with known ground truth. Include full-KV-wrong calls as controls, while estimating excess errors on full-KV-correct calls. Teacher-force the shared prefix to locate the first value divergence, then separately score freely generated calls to avoid reporting a teacher-forced detector as an online result. Tune the alert on a different task family and evaluate unseen schemas. If a fixed conservative budget or simple always-replay policy matches the error/latency frontier, stop. A single model can screen for signal. A second model and replay under mixed load are needed for broader claims. Local synthetic fixtures can verify labels. Access to a CUDA model with both raw scores and physical eviction is unconfirmed. No new experiment ran.

## Search limits

Searched adaptive agent cache budgets, tool-call exactness under eviction, grammar masking and confidence, serving integration and KV-cache compression developer guidance. The July 2026 merged runtime PR is concrete evidence that physical compaction and position accounting exist [K11]. Private serving traces, the original ActKV monitor’s exact runtime tap in a grammar-enabled backend, allocator costs under a real workload, and newer versions of all anchor papers were outside this sweep.
